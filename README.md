# dio-lab-az900
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab do curso de Formação Microsoft AZ-900 Certification na DIO.me.

Resumo dos termos e aprendizados deste lab:
  -CapEx - Despesas de capital
  -OpEx - Custos operacionais
  -On Premisses - Inraestrutura local na empresa
  -Nuvem Privada - Estrutura de uma única empresa
  -Nuvem Publica - Mesma estrutura compartilhada por diferentes empresas
  -Hibrida - combinação de parte privada e parte publica.
  -Criação de conta gratuita na AZURE
  -Cuidados e atenção com uso de recursos e cobranças.
